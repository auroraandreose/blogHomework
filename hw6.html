Application: strategia Buy/Sell su un GBM

In questo homework utilizzo il Geometric Brownian Motion simulato nell’homework precedente per rappresentare l’andamento del prezzo di un asset. Successivamente applico una semplice strategia di trading di tipo trend following: si compra quando il prezzo tende a salire e si vende quando il prezzo tende a scendere. Infine calcolo il PnL, cioè il profitto o la perdita complessiva della strategia, e il Maximum Drawdown, che misura il massimo calo del PnL rispetto al valore massimo raggiunto in precedenza.

Codice utilizzato

La simulazione parte dalla generazione di un prezzo tramite GBM. La strategia osserva la variazione del prezzo: se il prezzo aumenta viene mantenuta una posizione di acquisto, mentre se il prezzo diminuisce la posizione viene chiusa. Il PnL cumulato viene poi aggiornato lungo tutta la traiettoria.

JavaScript

function applyTradingStrategy(prices) {
  const pnl = [0];
  const positions = [0];

  let position = 0;
  let tradeCount = 0;

  for (let i = 1; i < prices.length; i++) {
    const stepPnL = position * (prices[i] - prices[i - 1]);
    pnl.push(pnl[i - 1] + stepPnL);

    if (prices[i] > prices[i - 1] && position === 0) {
      position = 1;
      tradeCount++;
    } else if (prices[i] < prices[i - 1] && position === 1) {
      position = 0;
      tradeCount++;
    }

    positions.push(position);
  }

  return { pnl, positions, tradeCount };
}

function computeMaximumDrawdown(pnl) {
  let runningMax = pnl[0];
  let maxDrawdown = 0;

  for (let i = 1; i < pnl.length; i++) {
    runningMax = Math.max(runningMax, pnl[i]);
    const drawdown = runningMax - pnl[i];
    maxDrawdown = Math.max(maxDrawdown, drawdown);
  }

  return maxDrawdown;
}

Theory: strategia Buy/Sell, PnL e Drawdown

Il Geometric Brownian Motion è un processo stocastico spesso utilizzato per descrivere l’evoluzione di un prezzo finanziario. La sua formula è:

\( S_t = S_0 \exp\left[\left(\mu - \frac{\sigma^2}{2}\right)t + \sigma W_t\right] \)
dove \( S_0 \) è il valore iniziale, \( \mu \) il drift, \( \sigma \) la volatilità e \( W_t \) il Moto Browniano.

Sul prezzo simulato viene applicata una strategia semplice: se il prezzo aumenta rispetto al periodo precedente, la strategia assume una posizione di acquisto; se invece il prezzo diminuisce, la posizione viene chiusa. In questo modo la strategia cerca di seguire la direzione del mercato.

\( PnL_t = PnL_{t-1} + Position_{t-1}(S_t - S_{t-1}) \)
Se la posizione è pari a 1, il PnL segue la variazione del prezzo; se è pari a 0, il PnL resta invariato.

Il Drawdown misura la perdita rispetto al massimo valore del PnL raggiunto fino a quel momento. Il Maximum Drawdown è il drawdown massimo osservato lungo tutta la simulazione.

\( DD_t = \max_{s \leq t}(PnL_s) - PnL_t \)
Un valore elevato di Maximum Drawdown indica che la strategia ha subito una perdita rilevante rispetto al suo massimo precedente.

In conclusione, l’Homework 6 mostra come un processo stocastico possa essere usato per simulare un prezzo e per valutare una semplice strategia operativa attraverso due indicatori principali: il PnL finale e il Maximum Drawdown.
