Application: strategia Buy/Sell su un GBM

In questo homework utilizzo il Geometric Brownian Motion, già introdotto nell’homework precedente, per simulare l’andamento del prezzo di un asset finanziario. Su tale prezzo viene applicata una semplice strategia di trading di tipo trend following: la strategia assume una posizione di acquisto quando il prezzo sale rispetto al periodo precedente e chiude la posizione quando il prezzo scende. Infine vengono calcolati il PnL finale e il Maximum Drawdown.

Codice utilizzato

Il codice genera prima una traiettoria browniana discreta e poi costruisce il prezzo tramite GBM. Successivamente applica la strategia Buy/Sell: se il prezzo aumenta rispetto al periodo precedente la posizione diventa pari a 1, mentre se il prezzo diminuisce la posizione diventa pari a 0. A partire dal PnL cumulato viene poi calcolato il Maximum Drawdown.

JavaScript

function applyTradingStrategy(prices) {
  const pnl = [0];
  const positions = [0];

  let position = 0;

  for (let i = 1; i < prices.length; i++) {
    const stepPnL = position * (prices[i] - prices[i - 1]);
    pnl.push(pnl[i - 1] + stepPnL);

    if (prices[i] > prices[i - 1] && position === 0) {
      position = 1;
    } else if (prices[i] < prices[i - 1] && position === 1) {
      position = 0;
    }

    positions.push(position);
  }

  return {
    pnl,
    positions
  };
}

function computeMaximumDrawdown(pnl) {
  let runningMax = pnl[0];
  let maxDrawdown = 0;

  for (let i = 1; i < pnl.length; i++) {
    if (pnl[i] > runningMax) {
      runningMax = pnl[i];
    }

    const drawdown = runningMax - pnl[i];

    if (drawdown > maxDrawdown) {
      maxDrawdown = drawdown;
    }
  }

  return maxDrawdown;
}

Theory: strategia Buy/Sell, PnL e Drawdown

In questo homework il GBM viene utilizzato come base per simulare un prezzo finanziario. L’obiettivo principale non è più descrivere il processo stocastico in sé, già analizzato nell’homework precedente, ma utilizzare tale processo per costruire e valutare una semplice strategia operativa.

La strategia adottata è una strategia Buy/Sell di tipo trend following. L’idea è quella di seguire la direzione del mercato: se il prezzo aumenta rispetto al periodo precedente, la strategia assume una posizione di acquisto; se invece il prezzo diminuisce, la posizione viene chiusa.

\( Position_t = \begin{cases} 1 & \text{se } S_t > S_{t-1} \\ 0 & \text{se } S_t < S_{t-1} \end{cases} \)
La posizione vale 1 quando la strategia è investita e 0 quando resta fuori dal mercato.

Il PnL, cioè Profit and Loss, misura il profitto o la perdita generata dalla strategia. Se la posizione è pari a 1, il PnL cambia in base alla variazione del prezzo; se invece la posizione è pari a 0, il PnL rimane invariato.

\( PnL_t = PnL_{t-1} + Position_{t-1}(S_t - S_{t-1}) \)
Il PnL finale rappresenta il risultato complessivo della strategia.

Il Drawdown misura la perdita rispetto al massimo valore del PnL raggiunto fino a un certo istante. Questo indicatore è utile perché permette di valutare non solo il risultato finale della strategia, ma anche il rischio sostenuto durante la simulazione.

\( DD_t = \max_{s \leq t}(PnL_s) - PnL_t \)
Il Maximum Drawdown è il valore massimo assunto dal drawdown lungo tutta la traiettoria.

In conclusione, l’Homework 6 mostra come un processo stocastico possa essere utilizzato non solo per simulare un prezzo, ma anche per valutare una strategia di trading attraverso due indicatori principali: il PnL finale e il Maximum Drawdown.
