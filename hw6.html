Application: strategia Buy/Sell su un GBM

In questo homework utilizzo il Geometric Brownian Motion simulato nell’homework precedente come processo stocastico per rappresentare il prezzo di un asset. Su tale processo viene poi applicata una semplice strategia di trading basata su regole di buy e sell. Infine vengono calcolati il PnL, cioè il profitto o la perdita complessiva, e il Maximum Drawdown, che misura il massimo declino del PnL rispetto al massimo precedente.

Codice utilizzato

Il codice genera prima una traiettoria di GBM. Successivamente applica una strategia elementare: se il prezzo cresce rispetto al periodo precedente, la posizione diventa pari a 1, quindi si compra; se il prezzo diminuisce, la posizione diventa pari a 0, quindi si vende. Il PnL viene aggiornato in base alla posizione detenuta.

JavaScript

function applyTradingStrategy(prices) {
  const pnl = [0];
  const positions = [0];

  let position = 0;
  let buyCount = 0;
  let sellCount = 0;

  for (let i = 1; i < prices.length; i++) {
    if (prices[i] > prices[i - 1] && position === 0) {
      position = 1;
      buyCount++;
    } else if (prices[i] < prices[i - 1] && position === 1) {
      position = 0;
      sellCount++;
    }

    const dailyPnL = position * (prices[i] - prices[i - 1]);
    pnl.push(pnl[i - 1] + dailyPnL);
    positions.push(position);
  }

  return { pnl, positions, buyCount, sellCount };
}

function computeMaximumDrawdown(pnl) {
  let runningMax = pnl[0];
  let maxDrawdown = 0;

  for (let i = 1; i < pnl.length; i++) {
    if (pnl[i] > runningMax) {
      runningMax = pnl[i];
    }

    const drawdown = runningMax - pnl[i];

    if (drawdown > maxDrawdown) {
      maxDrawdown = drawdown;
    }
  }

  return maxDrawdown;
}

Theory: strategia Buy/Sell, PnL e Drawdown

Il Geometric Brownian Motion è un processo stocastico spesso utilizzato per rappresentare l’evoluzione del prezzo di un asset finanziario. La sua espressione è:

\( S_t = S_0 \exp\left[\left(\mu - \frac{\sigma^2}{2}\right)t + \sigma W_t\right] \)
dove \( S_0 \) è il prezzo iniziale, \( \mu \) il drift, \( \sigma \) la volatilità e \( W_t \) il Moto Browniano.

Dopo aver simulato il prezzo tramite GBM, viene introdotta una strategia molto semplice. La regola scelta è di tipo trend-following: se il prezzo aumenta rispetto al periodo precedente, si assume una posizione di acquisto; se invece il prezzo diminuisce, si chiude la posizione.

\( \text{Position}_t = \begin{cases} 1 & \text{se } S_t > S_{t-1} \\ 0 & \text{se } S_t < S_{t-1} \end{cases} \)
La posizione vale 1 quando si è investiti nel mercato e 0 quando si resta fuori.

Il PnL, cioè profit and loss, misura il profitto o la perdita generata dalla strategia. Se la posizione è pari a 1, il PnL varia insieme al prezzo; se invece la posizione è pari a 0, il PnL rimane invariato.

\( PnL_t = PnL_{t-1} + Position_{t-1}(S_t - S_{t-1}) \)
Il PnL finale rappresenta il risultato complessivo della strategia.

Il Drawdown misura invece la perdita rispetto al massimo valore del PnL raggiunto fino a un certo istante. È quindi un indicatore utile per valutare non solo il guadagno finale, ma anche il rischio sostenuto durante la strategia.

\( DD_t = \max_{s \leq t}(PnL_s) - PnL_t \)
Il Maximum Drawdown è il valore massimo assunto dal drawdown lungo tutta la traiettoria.

In sintesi, questo homework mostra come un processo stocastico possa essere utilizzato non solo per simulare l’andamento di un prezzo, ma anche per testare una semplice strategia operativa e valutarne il risultato attraverso PnL e Maximum Drawdown.
